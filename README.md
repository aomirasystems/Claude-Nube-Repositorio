# Claude-Nube-Repositorio

Repositorio base por defecto de **aomirasystems** para sesiones de Claude Code en la nube.

Sirve como punto de partida limpio: cada sesión puede clonarlo, trabajar en una rama `claude/*` y abrir un PR en borrador.

## Estructura

- `CLAUDE.md`: contexto e instrucciones para Claude.
- `archive/`: código del proyecto anterior (TubeReply, un bot de respuestas a comentarios de YouTube). Ya no se mantiene.
