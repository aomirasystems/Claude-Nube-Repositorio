## B. Numbers check
- Ingreso neto: 4,000 / mes. Gasto: 2,000 / mes = 24,000 / año. Ahorro: 2,000 / mes = 24,000 / año.
- Numero de libertad (regla de 25): 25 x 24,000 = 600,000. Equivale a retirar 4% = 24,000 / año.
- Años para llegar con aportes anuales de 24,000 a 5% real: FV = 24,000 x ((1.05^n - 1) / 0.05).
  - n = 16: 1.05^16 = 2.1829 -> 24,000 x 23.66 = ~567,800 (no llega).
  - n = 17: 1.05^17 = 2.2920 -> 24,000 x 25.84 = ~620,200 (supera 600,000). Resultado: "roughly seventeen years".
- Empieza a 28 -> retira a 45. Edad normal 65 -> 20 años antes.
- Amigo que ahorra 10%: 400 / mes = 4,800 / año; gasta 3,600 / mes = 43,200 / año; numero = 25 x 43,200 = 1,080,000.
  - 4,800 x ((1.05^n - 1) / 0.05) = 1,080,000 -> 1.05^n = 12.25 -> n = ln(12.25) / ln(1.05) = 51.4 años. Narracion: "more than fifty years".
- Aviso en el guion: simplificacion, impuestos y salud reales, colchon extra.
