## B. Numbers check
Rendimiento ilustrativo 6% anual, capitalizacion mensual (0.5% / mes). FV = P x ((1.005^n - 1) / 0.005).
- Persona que empieza a 25 con 500 / mes hasta 65 (n = 480): 500 x 1,991.5 = ~995,700 -> "roughly one million". Aporta 240,000.
- Sam empieza a 35 con 500 / mes hasta 65 (n = 360): 500 x 1,004.5 = ~502,300 -> "about half a million".
- Sam empieza a 35 con 1,000 / mes hasta 65 (n = 360): 1,000 x 1,004.5 = ~1,004,500 -> "about one million". Aporta 360,000 vs 240,000.
- Sam a los 45 (1,000 / mes, n = 120): 1,000 x 163.88 = ~163,900 -> "about one hundred sixty-four thousand".
- Amigo a los 45 (500 / mes desde los 25, n = 240): 500 x 462.04 = ~231,000 -> "about two hundred thirty thousand".
- Proyeccion de Sam de 45 a 65 con 1,000 / mes: ~1,004,500 total (consistente) -> "could reach about one million".
- No se cuenta aporte de empleador ni aumentos de aporte (se dice en la narracion).
